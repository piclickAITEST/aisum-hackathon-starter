# Videos that are ready to use

A list of videos that have already been analysed will be added here. Those come back
in seconds; a video nobody has run before has to be analysed first, which takes
minutes and can be refused while the service is busy.

Until the list is here, use the example video the **Video match** card starts with —
it has been analysed already, so it returns right away.

If a new video is refused with `RATE_LIMITED`, wait a few minutes and try once more, or
switch to the example video. Asking again straight away does not help: the limit does
not change while you wait.
