Built for AISUM Hackathon 2026. Signing in creates an account in a Google Cloud project AISUM operates. Your searches are sent to AISUM's services to produce results and are logged there against this app, not against your account. Privacy notice

What you'll check

Sign-in
Google accounts in an AISUM-operated project. Your user count for judging comes from here.
Product tools (MCP)
Turn a sentence, a photo, a scene or a YouTube video into products people can buy. You run all four here; the participant docs cover every option.
LLM gateway
The model your app talks to. One call to prove your key works, then one round trip where the model uses a product tool by itself.
Deploy
This same page on Cloud Run — see docs/deploy.md.

Scene match

          start_scene_match → get_scene_match_result

        longer
      

      
A photo plus what is going on in; products that fit the situation out.
        Two steps: start the job once, get a task_id, then ask again with that
        same id until it is done.

Video match

          start_video_match → get_video_match_result

        seconds to minutes
      

      
A YouTube URL in; products for each moment of the video, with
        timestamps. The same two steps as scene match. A video that has been run before
        comes back in seconds; a new one takes minutes.
